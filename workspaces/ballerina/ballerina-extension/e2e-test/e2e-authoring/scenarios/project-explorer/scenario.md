# Project Overview Scenario

Test the Project Overview (WorkspaceOverview) page in the WSO2 Integrator BI extension.

## Steps

1. Create a Ballerina workspace with one integration using the Welcome view.
2. Navigate to the WorkspaceOverview via the project explorer sidebar ("Open View").
3. Add a second integration from the WorkspaceOverview "Add" button.
4. Add a third integration from the WorkspaceOverview "Add" button.
5. Verify all three integration cards are visible in the overview grid.
6. Navigate into one integration by clicking its card and confirm the PackageOverview loads.
7. Navigate back to the WorkspaceOverview and delete one integration; verify its card is removed.
